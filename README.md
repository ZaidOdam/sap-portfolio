# Portfolio Website

Single-page React portfolio website for Zaidmohamed Odam, SAP SuccessFactors Consultant.

## Tech Stack
- React
- Vite
- Framer Motion (Animations)
- Lucide React (Icons)
- CSS (Custom SAP-inspired styling)

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```
